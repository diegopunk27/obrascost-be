# Commits

Use the same idea as the NestJS template:

```
#NROTarea : TÍTULO DESCRIPTIVO EN MAYÚSCULAS

Cuerpo: qué cambió y por qué (en español si el equipo lo pide).
```

- Task number from branch name when applicable (`feature/1234-descripcion` → `#1234`).
