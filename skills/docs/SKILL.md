# Documentation

- **README.md**: setup, run, test, migrate, Docker, architecture summary.
- **AGENTS.md**: agent/skill index and conventions.
- **OpenAPI**: docstrings and `response_model` on routers; keep tags consistent.
- **skills/**: short, actionable `SKILL.md` files with examples.

When adding a major pattern, update README + the relevant skill file.
