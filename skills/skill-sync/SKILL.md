# Skill sync

When adding or renaming a skill:

1. Update **AGENTS.md** skill mapping table (NestJS equivalent if any).
2. Update **Auto-invoke hints** in AGENTS.md if workflow changes.
3. Ensure **README.md** links to AGENTS/skills if the workflow is user-facing.

No automated script in this boilerplate — keep edits manual and small.
